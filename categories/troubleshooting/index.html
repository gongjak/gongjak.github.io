종일 매매 불가로 오인한 날, 진짜 문제는 -123,632원 실손실이었다

대시보드가 ‘운영 중단 권고’를 띄워 종일 매매 불가로 알았다. 포렌식하니 엔진은 정상이었다 — 매수 4건, 매도 2건. 신호는 오탐이었다. 그런데 조사 중 진짜 결함 2건(RT 필터 fail-open, assume_filled 체결가 오기록)이 드러났다. 당일 실손실은 -123,632원이었다.

DNS 순간 장애가 WebSocket을 종일 죽인 이유: 자동 복구 경로가 없었다

새벽 5시 DNS 순간 장애로 KIS WebSocket이 재연결 5회를 소진하고 영구 차단됐다. DNS가 복구된 후에도 WebSocket은 살아나지 않았다. 자동 복구 경로가 설계에 없었기 때문이다.

SQLModel timezone=True 한 줄이 만든 9거래일 체결 0건

Phase 124에서 DB 컬럼을 TIMESTAMP → TIMESTAMPTZ로 올렸는데, 대응하는 SQLModel 필드에 timezone=True를 빠뜨렸다. asyncpg가 매도 체결 저장을 거부하면서 9거래일간 체결이 한 건도 기록되지 않았다. /health는 계속 200이었다.
